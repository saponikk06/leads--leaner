# clean_leads.py — очистка файла с заявками

## Что делает
Приводит "грязную" таблицу заявок (Имя, Телефон, Дата заявки, Источник) к чистому виду:
- Телефон → `+7XXXXXXXXXX` (не телефон → «нет телефона»)
- Дата → `ГГГГ-ММ-ДД` (нераспознанная → помечается, строка не выбрасывается)
- Имя → аккуратный регистр, без лишних пробелов
- Убирает дубли по телефону
- Проблемные строки выносит в отдельный файл, а не теряет

## Установка
```
pip install pandas openpyxl python-dateutil
```

## Запуск
```
python clean_leads.py заявки.xlsx
```

Необязательные параметры:
```
python clean_leads.py заявки.xlsx --out-clean clean.xlsx --out-problems problems.xlsx
```

По умолчанию создаются `clean_output.xlsx` и `problem_rows.xlsx` рядом со скриптом.

Работает и с `.csv`/`.txt` на входе. Колонки должны называться (регистр неважен):
"Имя", "Телефон", "Дата заявки", "Источник".
